## 📖 Overview

In real-world projects, some files and directories should **not be tracked by Git**. These may include log files, temporary files, generated files, IDE-specific files, build artifacts, or sensitive local configuration files.

Git provides the **`.gitignore`** file to define rules that tell Git which files and directories should be excluded from version control.

In this hands-on lab, a `.log` file and a log directory will be created inside the existing `GitDemo` repository. The `.gitignore` file will then be configured to prevent Git from tracking them.

# 🚫 Part 4 — Create the `.gitignore` File

## 4.1 Create `.gitignore`

Create the `.gitignore` file:

```bash
touch .gitignore
```

> **📝 Windows Alternative**
> If required, `.gitignore` can also be created using Notepad++ and saved directly inside the `GitDemo` repository.

---

## 4.2 Add the Log File Ignore Rule

Open `.gitignore` using Notepad++:

```bash
notepad++ .gitignore
```

Add:

```gitignore
*.log
```

### What Does `*.log` Mean?

| Pattern | Meaning                             |
| :------ | :---------------------------------- |
| `*`     | Matches any file name               |
| `.log`  | Matches the `.log` extension        |
| `*.log` | Ignore all files ending with `.log` |

Examples of files ignored by this rule:

```text
application.log
debug.log
error.log
system.log
server.log
```

---

## 4.3 Ignore the Log Directory

Add another rule to `.gitignore`:

```gitignore
log/
```

The final `.gitignore` file should contain:

```gitignore
# Ignore all log files
*.log

# Ignore the log directory
log/
```

Save the file.

# 🧪 Part 6 — Verify Ignore Rules Explicitly

Git provides the `git check-ignore` command to determine which ignore rule is responsible for ignoring a file.

## 6.1 Check the `.log` File

Execute:

```bash
git check-ignore -v application.log
```

### Example Output

```text
.gitignore:2:*.log    application.log
```

This confirms that `application.log` is being ignored because of the `*.log` rule.

---

## 6.2 Check the Log Directory File

Execute:

```bash
git check-ignore -v log/system.log
```

### Example Output

```text
.gitignore:5:log/    log/system.log
```

> **💡 Observation**
> `git check-ignore -v` displays the `.gitignore` rule responsible for excluding a particular file.

# 📚 `.gitignore` Pattern Reference

| Pattern   | Purpose                             | Example               |
| :-------- | :---------------------------------- | :-------------------- |
| `*.log`   | Ignore all `.log` files             | `error.log`           |
| `log/`    | Ignore the complete `log` directory | `log/system.log`      |
| `*.tmp`   | Ignore temporary files              | `cache.tmp`           |
| `build/`  | Ignore build directory              | `build/classes/`      |
| `*.class` | Ignore Java compiled files          | `Main.class`          |
| `.idea/`  | Ignore IntelliJ IDEA settings       | `.idea/workspace.xml` |

> **📝 Note**
> Only `*.log` and `log/` are required for this hands-on exercise. The other patterns are examples of commonly used `.gitignore` rules.
