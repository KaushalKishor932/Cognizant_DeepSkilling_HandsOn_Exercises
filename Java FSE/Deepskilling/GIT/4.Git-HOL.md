## 📖 Overview

A **merge conflict** occurs when Git cannot automatically determine which changes should be retained while combining two branches.

This usually happens when the same portion of a file is modified differently in two separate branches.

In this hands-on lab, a branch named `GitWork` will be created. The same `hello.xml` file will then be modified differently in both `main` and `GitWork`. When the branches are merged, Git will intentionally generate a conflict.

The conflict will then be identified, resolved, committed, and verified using Git commands.

# 🧩 Part 13 — Understand Conflict Markers

Git inserts special markers to identify the conflicting versions.

| Marker            | Meaning                                    |
| :---------------- | :----------------------------------------- |
| `<<<<<<< HEAD`    | Beginning of the current branch version    |
| `=======`         | Separator between the conflicting versions |
| `>>>>>>> GitWork` | End of the incoming branch version         |

### Current Branch Version

```xml id="r33jwf"
<message>Hello from Main Branch</message>
```

### Incoming Branch Version

```xml id="pvhhhf"
<message>Hello from GitWork Branch</message>
```

> **💡 Key Concept**
> Git identifies the conflict but does not decide which content is correct. The developer must resolve the conflict.

# 🛠️ Part 14 — Resolve the Conflict Manually

Open `hello.xml` and replace the conflicting content with the final desired version.

For example:

```xml id="c18b3m"

```

The conflict markers must be completely removed.

### Final `hello.xml`

```xml id="fgyu9s"
<message>Hello from Main and GitWork Branches</message>
```

Save the file.

> **⚠️ Important**
> Do not leave `<<<<<<<`, `=======`, or `>>>>>>>` markers inside the resolved file.

# 🚫 Part 20 — Update `.gitignore` for Merge Backup Files

Some merge tools may create temporary backup files such as `.orig`.

To prevent these files from being tracked, open `.gitignore`:

```bash id="2nmzqe"
notepad++ .gitignore
```

Add:

```gitignore id="4q76uw"
# Ignore merge backup files
*.orig
```

The `.gitignore` file may now contain:

```gitignore id="etp74j"
# Ignore all log files
*.log

# Ignore log directory
log/

# Ignore merge backup files
*.orig
```

---

## 20.1 Commit `.gitignore` Changes


> **💡 Observation**

|   **12. Push**  | `git push origin main`   | Resolution synchronized     |
